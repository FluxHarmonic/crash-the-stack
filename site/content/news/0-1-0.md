# 0.1.0, the first release

This is the first release of Crash The Stack that anyone else can play, and after three abandoned attempts at this same game it feels good to write that sentence!

What's in it: STACK, which is Mahjongg solitaire with a trace counting down; DEFRAG, which is Klondike with packets instead of playing cards; and the overworld hub that ties runs together. You can play it in a browser at [/jack-in/](/jack-in/), and you can install it as an app from your phone's browser menu.

It's a 0.1, so I want to be straight about what that means. The games are complete and the rules are what you would expect. The parts around them are still early. There's more to come in the hub, the music is still being written, and some of it will change under you between now and 1.0.

The [About page](/about/) has the longer version of what this is and how it's made.
