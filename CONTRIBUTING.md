# Contributing

Issues are welcome: a bug with the seed or share code of the board it
happened on (the pause menu's CODE line), the browser or the build, and
what you expected. A tune for the tracker is a fine thing to share too;
a link from the tracker's share button is enough.

Pull requests by discussion first: open an issue with what you want to
change and why, and we'll talk before anyone writes code. The game's rules
are the classics' and stay that way; the theme, the modes and the plan are
mine, and I review every line that lands. That's how the whole thing was
built, and it doesn't change with a public repo.

Code style is in `CLAUDE.md` (it is the same for a person). The tests are
`scripts/dev sigil test`; the browser arms are the `verify-*.mjs` scripts.
The commit log is the development log: write the message for someone
reading it in a year.
