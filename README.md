# Crash The Stack

Cyberpunk takes on the classics: Mahjongg solitaire, Klondike, and more, built in
Sigil for desktop and web.

Design and plan live in the author's notes for now; this repository is private
until the 0.1 release. Game code is GPL-3.0-or-later (`LICENSE`); art, audio and
content are CC-BY-4.0 (`assets/LICENSE`) except the reserved marks in
`assets/RESERVED.md`.
