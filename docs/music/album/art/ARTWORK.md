## Exact prompt

Use case: compositing. Create one finished square 1024x1024 album cover for the game Crash The Stack using these existing game assets. Input 1 is the actual game's pixel-art tower backdrop, input 2 is the actual two-line game title logo, input 3 is a four-frame sprite sheet of the pixelated Flux Harmonic publisher mark. Use ONLY the fully resolved rightmost frame's Flux Harmonic mark from input 3, not four logos. Preserve the recognizable lettering, spelling and proportions of both marks; do not redesign them. Compose a square album sleeve with the cyan-to-magenta CRASH / THE STACK title across the upper area, the ominous violet tiered cybernetic tower as the central artwork, cyan and magenta light accents and small orange lights. The title must not touch or clip the edges. Add a small crisp pixel-lettered subtitle 'ORIGINAL SOUNDTRACK' just below the game title. Place one relatively small white-and-orange Flux Harmonic mark centered toward the bottom with breathing room around it, clearly secondary to the game title. Keep the darkness, low-resolution pixel clusters, ordered dithering, limited palette and retro computer-game feel of the supplied actual assets; no smooth illustrated reinterpretation, no photography, no bevel mockup, no extra invented logos, no UI, no track listings, no additional text. It should feel like the title screen recomposed as an album cover, modern dark electronic music with 8-bit roots. Flat edge-to-edge cover artwork, not a physical album photograph.
